# منصة التطوع الليبية

منصة وطنية مفتوحة المصدر تجمع الجمعيات والشركات والمبادرات التطوعية والخدمات المجتمعية في ليبيا، وتتيح للناس البحث عن فرص التطوع وطلب الخدمات والإبلاغ عن المحتوى غير المناسب.

## المميزات

- **دليل الجهات:** تصفح الجمعيات والشركات حسب المجال والمدينة، وصفحة تفاصيل لكل جهة.
- **الانضمام كمتطوع:** إرسال طلب تطوع إلى الجهة المختارة.
- **طلب خدمة اجتماعية:** إرسال طلب إلى الجهات المناسبة.
- **صفحة المتطوع:** إنشاء صفحة شخصية برابط خاص للمشاركة.
- **المبادرات التطوعية:** عرض المبادرات وإضافة مبادرة جديدة.
- **إضافة جهة:** نموذج لإضافة جمعية أو شركة أو مبادرة.
- **البلاغات:** نموذج عام للإبلاغ عن محتوى غير مناسب، وعرض آخر البلاغات.
- **لوحة إدارة:** لمراجعة الجهات الجديدة والطلبات والبلاغات، وتظهر لمن يملك صلاحية التعديل فقط.
- **لغتان:** العربية والإنجليزية، مع دعم الاتجاه من اليمين إلى اليسار والوضع الداكن.

## التشغيل

الملف واحد ولا يحتاج إلى تثبيت. افتحه في أي متصفح حديث. للنشر على GitHub Pages، أعد تسمية الملف الرئيسي إلى `index.html` وارفعه إلى المستودع.

## الوضع الحالي والمهام المتبقية

الحفظ الحالي يتم في متصفح كل زائر فقط، أي أن البيانات لا تظهر لبقية الزوار. المهام المتبقية لتحويله إلى منصة عامة:

- [ ] ربط قاعدة بيانات مشتركة (مثل Firebase Firestore) لحفظ الجهات والطلبات والبلاغات.
- [ ] تسجيل دخول آمن للمشرفين (مثل Firebase Authentication).
- [ ] صفحة سياسة خصوصية توضح البيانات المجمعة.
- [ ] مراجعة الصور والشعارات المضمّنة في الملف والتأكد من حقوق استخدامها.
- [ ] اختبار الواجهة على الهواتف المختلفة.
